# Changelog

## 0.1.0

- Extract imagery and terrain LOD transitions into an independent package with a per-Viewer runtime adapter for unmodified CesiumJS 1.145.x.
- Provide ESM, CommonJS, browser-global builds and TypeScript declarations.
- Add independent feature switches, duration control, debug coloring, resource budgets, automatic fallback, reset and deterministic cleanup.
- Include synthetic diagnostic examples for unminified and minified Cesium, controller/lifecycle tests, and recorded integration validation.
- Mark terrain transitions experimental and document seam, depth, picking and clamped-object limitations.
